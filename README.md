# Call Centre Dashboard – 2023

An interactive Call Centre Dashboard created in Microsoft Excel to analyze call volume, call trends, revenue, customer ratings, caller demographics, representative performance, and daily call activity.

## Project Overview

This project focuses on transforming call centre data into an interactive and easy-to-understand dashboard using Microsoft Excel.

The dashboard provides a high-level view of call centre performance and helps identify trends across calls, revenue, customer ratings, representatives, locations, and days of the week.

## Dashboard Features

### Call Trends
Shows the monthly trend of calls throughout 2023 and helps identify months with higher or lower call volumes.

### Female vs Male Callers
Compares the number of female and male callers across different cities.

### Customer Rating
Visualizes the distribution of customer ratings from 0 to 5.

### Calls by Representative
Compares the number of calls handled by each representative.

### Amount by Representative
Shows the total amount associated with each representative.

### Calls by Day
Analyzes call volume across different days of the week.

### Representative Filter
Allows users to filter and explore dashboard data by individual representatives.

### Detailed Call Centre Data
Provides a detailed view of calls, amounts, representatives, locations, and other relevant information.
